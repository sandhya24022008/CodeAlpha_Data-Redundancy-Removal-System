# CodeAlpha_Data-Redundancy-Removal-System

Project Description

This project is designed to identify and prevent duplicate data in a database. It checks whether a record already exists before adding new data.

Technologies Used

- Python
- SQLite Database

Features

- Validates input data
- Checks for duplicate records
- Prevents redundant data storage

How to Run

1. Install Python.
2. Run "main.py".
3. Enter the required data to check for duplicates.
